O que é o Pipenv?

O Pipenv é uma ferramenta que facilita a vida de quem trabalha com Python. Ele combina duas tarefas que antes precisavam ser feitas separadamente:

  1. Criar e gerenciar ambientes virtuais (com virtualenv).
  2. Instalar e controlar dependências (com pip).

Com o Pipenv, essas etapas ficam integradas em um único fluxo. É como ter uma agenda inteligente que, além de organizar suas reuniões, ainda garante que todas estejam na hora certa e no lugar certo.

O Pipenv cria e gerencia automaticamente ambientes virtuais para cada projeto. Ele também mantém um arquivo chamado Pipfile, onde ficam listadas as bibliotecas que o seu projeto usa. Além disso, gera o Pipfile.lock, que registra exatamente as versões dos pacotes instalados — garantindo que qualquer pessoa que clone o projeto possa reproduzir o mesmo ambiente sem surpresas.

Instalar pipenv

pip install - user pipenv

Iniciar um projeto com Pipenv

Para começar, você pode simplesmente rodar o comando abaixo. Ele cria a estrutura básica de um ambiente virtual:

pipenv install

Se quiser já instalar um pacote ao criar o projeto, basta incluir o nome dele:

pipenv install flask

Para pacotes de desenvolvimento (como frameworks de teste ou ferramentas de lint), use a flag -d:

pipenv install -d pytest

Para entrar e sair do shell do ambiente virtual:

pipenv shell
deactivate

👉 Pense no pipenv shell como a chave que liga o motor do seu projeto. Enquanto estiver dentro dele, todos os comandos Python vão rodar isolados daquele ambiente. Ao sair (deactivate), você volta para a sua máquina “normal”.

Atualizar pacotes do projeto

Para identificar pacotes desatualizados:

pipenv update --outdated

Para atualizar todos os pacotes ou apenas um específico:

pipenv update
pipenv update <nome_pacote>

Gerenciando o ambiente virtual

Visualizar a localização do ambiente virtual atual:

pipenv --venv

Excluir o ambiente virtual:

pipenv --rm

Listar as dependências de forma estruturada (incluindo subdependências):

pipenv graph

Esse comando é especialmente útil quando seu projeto começa a crescer e você precisa entender “quem depende de quem”. É como abrir o mapa de ligações de uma cidade para enxergar quais ruas levam a quais destinos.

Conclusão

Neste post vimos os principais comandos do Pipenv que tornam o gerenciamento de ambientes virtuais e pacotes muito mais prático no dia a dia.

Para se aprofundar, vale explorar as referências abaixo e, principalmente, o repositório oficial do projeto no GitHub. Lá você encontrará exemplos avançados e explicações detalhadas para casos específicos.
