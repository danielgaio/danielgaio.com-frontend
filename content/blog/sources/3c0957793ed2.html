Se você adora o GitHub Copilot, mas não quer pagar por ele (ou quer que seu código permaneça 100% privado), a boa notícia é que você pode criar uma alternativa gratuita ao Copilot rodando inteiramente no seu laptop.

Neste guia, mostrarei como configurar o Ollama, o DeepSeek Coder e a extensão Continue dentro do VS Code para criar sua própria experiência “semelhante ao Copilot”.

Componentes Principais

Ollama: Um runtime leve que permite baixar e executar modelos de linguagem grandes (LLMs) localmente. Pense nele como um “Docker para modelos de IA”.

DeepSeek Coder: Um modelo de geração de código de código aberto treinado para tarefas de programação. É menor que o GPT-4, mas bom o suficiente para autocomplete e assistência ao código.

Continue: Uma extensão gratuita e de código aberto do VS Code que traz funcionalidades semelhantes às do Copilot. Ela se conecta a modelos de IA (locais ou remotos) e fornece autocomplete, refatoração e explicações de código.

Passo 1: Instale o Ollama

O Ollama executa o modelo localmente na sua máquina.

brew install ollama

Inicie o servidor Ollama:

ollama serve

Por padrão, ele roda em http://localhost:11434.

Passo 2: Baixe um Modelo de Codificação

O DeepSeek Coder é uma ótima alternativa de código aberto para autocompletar código.

Você pode baixar a versão 6.7B, que roda bem em Macs modernos:

ollama pull deepseek-coder:6.7b

Se você tem recursos limitados → tente deepseek-coder:1.3b.

Se você tem uma máquina potente (M2 Pro/Max, 32 GB+ RAM) → tente deepseek-coder:33b para obter melhores resultados.

Passo 3: Instale o Continue no VS Code

1. Abra o VS Code.
2. Acesse Extensões (Cmd+Shift+X no Mac).
3. Procure por Continue e instale-o.

O Continue adiciona um assistente em linha (acionado por Cmd+I) e um painel de chat na barra lateral (Option+Cmd+B).

Etapa 4: Conecte o Continue ao Ollama

Abra o arquivo de configuração do Continue (ícone de engrenagem Configurações -> Modelos -> Adicionar modelo -> arquivo de configuração (na parte inferior)).

Adicione estas configurações de modelo (altere de acordo com suas necessidades):

name: Local Agent
version: 1.0.0
schema: v1
models:
 - name: Qwen2.5-Coder 1.5B
 provider: ollama
 model: qwen2.5-coder:1.5b-base
 roles:
  - autocomplete
 - name: Nomic Embed
 provider: ollama
 model: nomic-embed-text:latest
 roles:
  - embed
 - name: Llama 3.2 3B
 provider: ollama
 model: llama3.2:3b
 - name: deepseek-coder:1.3b
 provider: ollama
 model: deepseek-coder:1.3b

Para o modelo ser listado na seleção de modelos no chat, você pode simplesmente omitir o campo roles.

Agora, o Continue se comunicará diretamente com o serviço Ollama em execução local.

Etapa 5: Use o Continue como o Copilot

Abra um arquivo de código.

Posicione o cursor onde deseja um autocomplete e comece a escrever seu código.

Selecione um bloco de código que deseja editar e pressione Cmd+I para abrir a área de texto onde você pode pedir quais modificações deseja → o modelo gerará sugestões em linha.

Abra a barra lateral (Option+Cmd+B) → converse com o modelo sobre seu código, solicite explicações ou gere novas funções.

Etapa 6: Alternando entre o GitHub Copilot e o Continue

Às vezes, você pode querer voltar para o GitHub Copilot. Para evitar que o Ollama concorra com o Copilot, você pode parar o servidor Ollama com Ctrl+C no terminal e desativar a extensão Continue no VS Code, ativando apenas a extensão do GitHub Copilot e vice-versa.

Isso facilita a alternância entre o GitHub Copilot (nuvem) e o Continue com o Ollama (local).

Prós e Contras vs. GitHub Copilot

Prós:

✅ 100% gratuito
✅ Totalmente privado (o código nunca sai da sua máquina)
✅ Funciona offline
✅ Você pode escolher o modelo (DeepSeek, Code Llama, StarCoder, etc.)

Contras:

⚡ Mais lento que o Copilot (depende do seu hardware)
📏 Modelos menores = menos precisos que o GPT-4
⚙️ Requer alguma configuração

Conclusão

Com apenas três ferramentas gratuitas — Ollama, DeepSeek Coder e Continue — você pode transformar o VS Code em uma alternativa gratuita ao Copilot que respeita sua privacidade e não requer assinatura.

E a melhor parte? Você pode alternar entre o GitHub Copilot e seu Copilot local sempre que quiser, iniciando ou encerrando o Ollama.

Experimente e veja quanto controle você ganha sobre seu fluxo de trabalho e desenvolvimento!
